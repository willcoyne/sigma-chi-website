## Functionality
- ✅ **Done** — The contact form (`src/components/ContactForm.tsx`) now has real submission logic (posts to Formspree via fetch) and collects recruitment-relevant fields (Year, Major, "How did you hear about us?") in addition to Name/Email/Message. **Still needed from a real person:** sign up for a free account at https://formspree.io, create a form, and put its endpoint URL into `VITE_FORMSPREE_ENDPOINT` in a local `.env`/`.env.local` file (see `.env.example` at the project root). Until that's done, the form runs in local-only demo mode (validates and shows success, but doesn't send anywhere) — which is the current default, safe behavior.
- ✅ **Done** — A structured Markdown content pipeline now exists for the History timeline: entries live as individual files under `src/content/timeline/*.md` and are loaded at build time. See `CONTENT-GUIDE.md` for non-developer instructions on editing/adding/removing entries without touching component code. (Philanthropy/colony content still live in `src/data/content.ts` as plain data, not Markdown — a future pass could extend the same pattern there if the colony wants to edit those sections directly too.)
- ✅ **Done (scaffolding)** — Analytics support was added (`src/lib/analytics.ts`, wired into `src/main.tsx`). **Still needed from a real person:** sign up for a free account at https://plausible.io, register the site's domain, and set `VITE_PLAUSIBLE_DOMAIN` in `.env`/`.env.local` (see `.env.example`). Until that's done, no analytics script loads and no third-party request is ever made — the current default.
